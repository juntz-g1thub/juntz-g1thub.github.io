# Welcome to My New Blog

Published: 2026-03-06
Tags: Blog, Introduction

Welcome to my new blog! This is my first blog post, introducing this zero-build blog project.

## Why Zero-Build?

My previous blog used Eleventy (a static site generator), but I found it too complex. So I decided to go back to basics:

### Core Design Principles

1. **Simple** - No build steps required
2. **Fast** - Browser renders Markdown directly
3. **Transparent** - All code is pure HTML/CSS/JS
4. **Flexible** - Fully customizable interface styles

## Tech Stack

This blog uses the simplest tech stack possible:

- **HTML5** - Page structure
- **CSS3** - Styling (with dark mode support)
- **JavaScript** - Core logic (~200 lines of code)
- **marked.js** - Markdown rendering (CDN)

No Webpack, Babel, NPM, not even Node.js needed!

## How It Works

1. Browser loads a single HTML page
2. JavaScript fetches Markdown files
3. marked.js converts Markdown to HTML
4. Page content is updated

The entire process happens in the browser.
